# PC Monitoring PRO

Десктопное приложение для мониторинга аппаратных ресурсов компьютера в реальном времени.
Это мой учебный проект.

## Возможности

- **Мониторинг в реальном времени** — загрузка и температура CPU/GPU, использование RAM с графиками LiveCharts
- **Информация о системе** — CPU, GPU, материнская плата, RAM, диски
- **История метрик** — статистика (мин/макс/сред) за 1ч, 24ч, 7д, 30д с таблицей записей
- **Системные уведомления Windows** — предупреждения при перегреве CPU/GPU через уведамления Windows
- **Настройки** — пороговые температуры CPU/GPU с сохранением в JSON
- **Тёмная и светлая тема** — плавная анимация переключения
- **Tray-иконка** — сворачивание в трей, контекстное меню

## Технологии

- **.NET 10.0 WPF**
- **LibreHardwareMonitorLib**
- **LiveChartsCore.SkiaSharpView.WPF**
- **SQLite**

## Настройки

Пороговые температуры сохраняются в `settings.json` в директории приложения. Значения по умолчанию: CPU — 90°C, GPU — 85°C.
